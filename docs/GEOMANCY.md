# 地占术·沙盘起占 v1

本版实现 Geomancy 的基本盾形图。它与风水、八卦、Ifá 分开，不含十二宫断法，也不含额外第16「调和者」。

## 来源与核对

S1：[《Of Geomancy》，Robert Turner 英译，1655，Princeton 托管电子转录](https://swh.princeton.edu/~ezb/geomancy/agrippa.html)。2026-09-30核对开篇十六图表 [hcafig1.gif](https://swh.princeton.edu/~ezb/geomancy/hcafig1.gif)、母女生成段落以及基本盾图 [hcafig4.gif](https://swh.princeton.edu/~ezb/geomancy/hcafig4.gif)。该篇署名 Agrippa，归属问题不影响本版明确采用的 Turner 1655 文本范围。

工程核对实际打开并逐行查看了图版，而非根据图名猜编码。仅采用文中从点列、母图到女图、两两合成和两证人、裁判的基础结构；紧接其后的另一种宫位排列、星占配置和十二宫判断均未引入。

古籍1655文本为公版资料；本项目保存的是核对后的图形事实、名称和原创中文释义，不复制托管站点的现代编辑文字或图版作为美术资源。所有沙面、点图与连线均为本站原创 CSS/SVG。图名的英文意译仅作别名，中文名称是本站译名。

编码1是一点，0是两点，每图四行自上而下。`data.ts`全部16项包含ID、名称、拉丁名、别名、关键词、主题、原创基础释义、适用条件、限制和来源。「传统图名」与「本站白话」分开，不把原创象征联想冒充古代断辞；不展示原典的灾祸、疾病或他人品性判定。

## 输入与推演

亲手模式分4组、每组4行。每次点击或键盘空格只生成一个实际可见点，附带单调递增的唯一ID和归一化位置。点按位置吸附到邻近空网格，避免重复点在同处互相遮盖；这只安排画面，不改变点数。无帧回调计点，无长按连点；触控取消不提交。Enter结束当前行。空行不可提交，每行上限128点且提前公开；达到上限保留现有点并明确提示。只可清空未提交行，ID不重用；提交后不能重画。

实物模式一次填写16行1–999999正整数；空值、小数、0、指数写法均拒绝。大数量在沙迹中明确缩略显示，实际算法使用完整数值。自动模式在用户提交问题时由共享 `RandomSource` 和 `uniformInt`一次预生成16个5–36点数，期间不显示；用户选此模式才展开。32个等可能整数含16奇、16偶，这是本站模拟约定，不是古籍规定范围。

前四行产生M1，之后每四行依次产生M2–M4。D1取四母的第一行，D2取第二行，以此类推（转置）。合成规则为逐行XOR：同值得0、异值得1。

```
N1=M1⊕M2    N2=M3⊕M4    N3=D1⊕D2    N4=D3⊕D4
W1=N1⊕N2   W2=N3⊕N4
J=W1⊕W2
```

屏幕顶行从左至右是D4、D3、D2、D1、M4、M3、M2、M1；第二行N4、N3、N2、N1；第三行W2、W1；底部J。因此第一证人W1始终在屏幕右侧、来自母图一侧，W2在左侧、来自女图一侧。每个图位可点击查看原始行号或直接父图及XOR等式。绘图、ID、解释和数据均沿用该约定，不按屏幕镜像改换身份。

点数归约、四母入位、女图转置、四侄合成、证人合成、裁判形成按步骤演示。可暂停、逐步或跳过；系统减少动态效果或全局暂停时不自动推进。动画仅揭示已经确定的盾图，不消耗随机源。结果提供「看沙迹／看盾图／看解读」。

## 解读、恢复与验证

基础解释使用W1、W2及J的实际图形与关系，母图和其余位置可单独观察。两侧有共通主题就指出共通点，不同则保留差异；裁判是派生结果，15位不是15票。W1母图一侧、W2女图一侧的象征观察写明为本站组织方式，不自称完整传统判断。没有专属行动适配规则，一律「无明确倾向」，开放问题不变成宜忌。

`GeomancyState`版本1保存预生成点数、模式、全部手点与ID、输入草稿、已提交行、完整原始盾图、演示进度和视图。受控组件不重新抽取。Zod恢复校验16图派生一致性、手点与数量一致、唯一ID、模式与阶段；`canTransitionGeomancy`另约束活动记录不可换种子、改已提交行或跳改推演。刷新与历史使用原状态，保存由宿主统一处理。

定向测试覆盖16图全表、固定母女转置算例、65536组母图的裁判偶点不变量、输入错误、随机源消耗、全部模式、只读提交、演示/跳过一致、损坏恢复和合法状态转移。实际命令与结果另回报主任务，不将尚未执行的浏览器检查写为通过。
