## 限制和没有声称的结果

- Playwright 自带 Chromium 在本地下载出现 TLS 传输失败，因此本地实际跑的是已安装 Chrome；没有把失败的下载当作浏览器测试通过。
- Vite 有单个 JS 包超过500 kB的体积提示。当前约726 kB未压缩／242 kB gzip，包含完整本地知识、农历库、界面和恢复校验；为了加载后立即离线可用，没有把引擎拆为延迟联网下载。这是体积提示，不是构建错误。
- 浏览器测试覆盖 Chromium 桌面／手机模拟和开发StrictMode，未执行 Safari、Firefox、真实iPhone硬件或所有年份的历法穷举。
- 自动测试不验证占卜“准确率”，本项目不作任何此类主张。
- GitHub Actions 的实际状态和公开部署结果以仓库 Actions 和 Pages 为准；本记录中的通过数是已执行的本地验证结果。
