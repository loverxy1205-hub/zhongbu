# 咖啡渣占 · 翻杯观纹 v1

本模块采用土耳其咖啡饮后倒扣、观察杯渣的文化体验路线。它生成原创虚拟杯纹，由用户自己框选与命名；没有图像识别、照片上传、预抽意象或预测评分。

## 来源核验（2026-09-30）

- **S2：[UNESCO 决议 8.COM 8.28](https://ich.unesco.org/en/decisions/8.COM/8.28)**：记述土耳其咖啡文化，提到空杯中残渣被用于观占，并决定将该文化列入代表作名录。此来源只支持文化及习俗存在，不能用来证明预测有效，不能给本站20条意象词典背书。核验时页面直接访问曾出现人机验证，官方站点搜索索引提供该决议完整正文，交叉核对了项目号00645与2013年列入信息。
- **S3：[GoTürkiye · Turkish Coffee Culture](https://goturkiye.com/blog/turkish-coffee-culture)**，节 _Reading Coffee Grounds: A Popular Fortune-Telling Ritual_：描述饮尽咖啡后将杯倒扣在碟上，让剩余杯渣形成纹样，再进行解释。仅据此采用饮后翻杯观纹路线；没有照搬该文对未来的断言。

本站的轻转、覆碟、翻杯、1300ms沉降等待、揭杯是可操作的页面编排。并未指定必须三圈、顺时针或其他统一礼规；旋转方向与角度由用户选择。杯口／杯壁／杯底只表示图像位置，不对应未来远近、人物或吉凶。源码与全部SVG／释义为本站原创，未复制来源图片或商业占卜图案。

## 生成与冻结

共同入口在 `src/experiences/coffee/index.ts`：`createCoffee(rng)`、`coffeeSchema`、`interpretCoffee(state,input)`、`canTransitionCoffee(previous,next)` 和受控 `CoffeeExperience`。

- `kind: 'coffee', version: 1`；词典版本 `cf-symbols-1`；纹样规则 `texture.version: 1`。未知版本拒绝恢复，不重算替换旧杯。
- 只有创建时调用共享随机源，取得四个uint32。此后没有随机调用。`texture.ts` 以按索引的整数混合函数确定性展开这些种子，输入仅有种子与记录的净转角／累计转距，不含问题、场景、词典或意象。
- 覆碟事件调用 `buildCoffeeTexture`，保存最终98片矢量纹样：40片成组团块、14条流痕、44片团块周边细渣，保留大片空白。图形从未按鸟、树、环等轮廓生成。
- 使用直接确定性生成，不按动画帧模拟。渣纹是视觉模拟，不声称精确重建流体。动画跳过、暂停、换视角与刷新都不改变纹样。
- 纹样存储规范坐标 `u=0..1000`（杯柄起点周向）和 `v=0..1000`（中心／杯底到杯口）。局部片段允许跨周向接缝，展开图重复相邻副本并裁剪，俯视以极坐标映射。缩放／观察旋转只是投影，不重新生成。
- `texture.id`包含种子与轻转参数；保存完整点坐标而非大图或base64。严格恢复校验重新验证坐标与种子／规则是否一致。典型JSON是数万字节量级，不使用照片或IndexedDB首版路径。

净转角限±1440°，累计转距限2880°；达到界限不继续增加，页面提前显示上限。单次程序更新限±180°，按钮每次30°。取消触控不推进流程。

## 受控流程与观察

`residue → turn → covered → inverted → settling → settled → observe → complete`。

所有进度、转动参数、最终纹样、视角、正在编辑的框、说明文字、已保存版本都在 `CoffeeState` 中由父组件持久化。只有拖动的瞬时指针起点和等待计时器在组件内。卸载清理计时器；暂停／减少动态／跳过只完成等待阶段，不跳过观察或改变纹样。

揭杯后的首屏只有观察图、俯视／展开与视角控件，以及「框选一片区域」「没有看见清楚形状」。不提前展示意象词典。用户主动框选后才显示20个意象、其他、不确定。

框选在未缩放、未旋转的展开图进行，因此矩形坐标与冻结表面一一对应；切换到俯视时以同一周向／深度区域描边。框选编辑期间锁定视角控件，可拖动或用四个原生范围输入器纯键盘调整。观察框范围合法、最小宽高各5%；位置描述依据框中心：深度不足32%为杯底、82%以上为杯口附近、其余杯壁。这些界限是本站的图像分区约定，不是传统判词。

每版最多8片框选，每条说明最多160字，最多8个观察版本。每版必须显式完成，旧版本不可改写；新版本引用同一 `texture.id`。没有看到清楚形状是合法完成结果，记录为空，不补好兆头。多个意象是一杯的观察，不是多份独立证据。

`interpretCoffee`只在 `complete` 返回解释；输入仅为当前选中的观察版本、对应词典和用户主动选择的场景。20条均标「本站象征提示」，没有伪造传统原文。其他／不确定与空观察保留用户记录并给中性反思，不推导行动方向。

`canTransitionCoffee`约束四种不变量：种子不换、覆碟后纹样和转动参数不换、旧观察版本不改、流程不越级。它同时约束新标注必须来自显式草稿，以及完成版本必须对应当前已保存标注。父级先做schema校验再使用此守卫。

## 验证范围

`tests/coffee.test.ts`覆盖仅4次初始取样、确定性回放、视角不重画、流程守卫、20意象与其他／不确定、空观察、版本共用纹样且不可改旧版、数量上限、坏数据与越界坐标拒绝。页面还提供原生按钮／范围控件／下拉框完成全部键盘流程；本模块不请求网络资源。
