# 掷筊与灼甲体验 v1

## 掷筊

来源 S6：[桃园在地化课程／长祥宫「筊杯」](https://tlc.tyc.edu.tw/temples/changxiang-palace/)，2026-09-30实际读取核对。以朝上的面判别：一平一凸圣筊，两平笑筊，两凸阴筊。网页使用原创SVG月牙图；现代中文概述，不复制照片或大段现代文本。

`createJiaobei`在创建记录时从共享均匀随机源冻结三对独立二值。单次模式仅揭示首对；三次模式固定揭示三对。模式与完整命题在揭晓前确认，确认后不可改变。三次全圣是本站可选约定，不代表所有庙宇规矩；未达到条件不等于三次全阴，不自动重掷。

四种数字组合中圣／笑／阴分别有2／1／1种，这是模拟分布，不是现实事情成功概率，也不是对真实筊杯概率的测量。笑筊显示未明确答复，不写成反对。单独确认的命题完整保留，圣／笑／阴映射为对此命题的应允／未明确／不应允象征，不能反转否定。不把这一个命题的应允移植到首页其他选项，因此不参加多选项方向汇总。用户不补充命题时仍能文化演示，演示也排除主题归纳。

动画有合拢、上抛翻转与落地回弹，面向严格取自冻结二值；键盘可操作、可跳过／暂停／减少动态。离开组件取消等待，重进仍是同一次记录。

## 灼甲历史体验

S7：[Smithsonian 教案 Making Sense of the Future](https://asia-archive.si.edu/learn/for-educators/teaching-china-with-the-smithsonian/lesson-plans/making-sense-of-the-future-the-oracle-bone-and-shang-dynasty-divination/)；S8：[馆藏 S2012.9.445 教育页](https://asia-archive.si.edu/learn/for-educators/teaching-china-with-the-smithsonian/explore-by-object/inscribed-tortoise-shell-oracle-bone/)。用户提供的新站地址直读报错，2026-09-30实际读取同馆官方archive页面核对。只采用中文简短概述，不复制文物图像、现代整段翻译或仿写古文。

流程为虚拟整治、钻凿示意、现代文字记问、选择六处模拟灼点之一、程序化裂纹、用户观察、独立历史案例、未来主动追加实际结果。六处裂纹的数值坐标均在创建记录时生成并冻结，之后动画不再随机；每条裂纹首坐标必须等于相应灼点。图案为原创程序视觉，不是精确材料模拟或古法吉凶译码。没有购买甲片、处理动物或真实加热步骤。

三个可主动选择的主题入口只使用上述两页已核对内容：该甲片关于雨的铭文主题、获得二十鹿的事后记录，以及教案中另一条铭文的问辞／判断／验辞分栏示例。没有逐字释文就不展示伪造原文；案例明确独立于本次裂纹，不按自由问题关键词暗中推断主题。

首次观察与选定案例完成后冻结。事后记录可追加最多20条，每条1000字，保留写入时间，不覆盖首次解释或已有事后记录。JSON/Markdown包含状态与记录，可保存、恢复、收藏、复制与导出。本体验不参与主题或方向汇总，也没有中性分数，不调用模型补写判词。
