# 众卜 v1.3 · 算法与解释约定

本站不是预测模型，没有训练、准确率、置信度、成功概率或玄学评分。用途是文化体验与自我反思。五套引擎互不读取答案或用户偏好。

## 生命周期

`Input → calculate/draw → interpret → renderText → EngineResult → Reading`

`createReading` 只在显式提交事件执行。提交入口用同步 `ref` 锁防止双击；组件 render、effect、动画都不抽取。一次提交捕获一个 ISO 时间戳，生成由四个 uint32 组成的 readingId，深冻结输入（不含生日）、原始结果、解释、版本。日期型引擎不注入随机扰动。

`src/types.ts` 定义有判别字段的结果联合类型，没有无约束 any。`src/data` 是知识，`src/engines` 负责计算，`src/rules` 分别负责解释、文案和汇总，`src/lib` 管理存储及导出，`src/components` 呈现结果。

## 随机数

Web Crypto `getRandomValues(Uint32Array)`；均匀整数 `0..m-1` 使用拒绝采样：只接受小于 `floor(2^32/m)*m` 的值，再取模。无放回抽取使用部分 Fisher–Yates 洗牌。测试可注入 uint32 源。问题、生日、时间戳都不会成为随机种子。

## 塔罗

完整 78 张 RWS 名称：22 大阿尔卡纳、四花色各 14 张。强力／力量为 VIII，正义为 XI。三张依次是现状、阻力、提示。v1.2 新表单默认开启逆位，不提供开关；各张独立掷一次公平二值随机数，50% 逆位，这是本站约定。旧记录保持自身配置和结果。正逆位拥有分别整理的释义与主题。

位置模板独立：现状观察处境；阻力检视主题的不足、过度或牵制，不把它当直接行动建议；提示提供反思角度。人物牌不规定性别。死神象征收束更新，高塔象征原有结构被挑战，不指现实死亡或灾难。几何卡面为本站原创装饰，并非 RWS 商业牌图。

## 周易三枚铜钱

每轮三枚公平硬币，一面 2，另一面 3；和值 6 老阴、7 少阳、8 少阴、9 老阳。八种等可能组合的计数为 1/3/3/1。六轮自下而上，字符串第 0 位是初爻，前三位为下卦，后三位为上卦。1 为阳，0 为阴。仅 6/9 翻转；画图反向遍历以保证上爻在上。

64 卦编码完全唯一。并列阅读本卦卦辞、全部动爻、变卦卦辞；没有动爻时不伪造变化。保存乾坤用九／用六作为附录，本版不另外触发专门断法。未实现六爻纳甲、世应、六亲、择爻断法。

## 梅花年月日時

依据《梅花易數》卷一「年月日時起例」，使用**提交时冻结的问卜时刻**。浏览器 Intl 先转为用户指定的 IANA 时区当地公历年月日和小时，`lunar-typescript@1.8.6` 再转换农历。

Y 为农历年地支序（子 1 至亥 12），由农历年 `(year - 4) mod 12 + 1` 得到；不用公历年或立春年。M 为农历月绝对值，D 为农历日，H 为 `floor((hour+1)/2) mod 12 + 1`。

`R(n,m)=((n-1) mod m)+1`。上卦 `R(Y+M+D,8)`；下卦 `R(Y+M+D+H,8)`；动爻 `R(Y+M+D+H,6)`。八卦编号乾1、兑2、离3、震4、巽5、坎6、艮7、坤8。

样例 5、12、17、9：和 34/43；上兑2、下离3、初爻动。自下而上 `101110 → 001110`，革之咸。

工程约定：正月初一换年；闰月使用原月序数；零点换日；子时 23:00–次日01:00；不做真太阳时校正。采用本地民用日转换，未重新计算所选地理位置的新月。支持公历 **1901–2099**；超范围、无效时区、转换错误明确不可用。

动爻在初至三爻，下卦为用，上卦为体；四至六爻相反。五行：乾兑金、离火、震巽木、坎水、艮坤土。只比较比和、生、克；无旺衰、互卦、外应。周易与梅花属于相关体系，不是独立科学证据。

## 简化个人日

本站现代规则：reduce 反复逐位相加至1–9，不保留11/22/33。

- 生命数字：出生日期所有数字之和再 reduce。
- 个人年：出生月 + 出生日 + 目标公历年份数字和，再 reduce。
- 个人月：个人年 + 目标月份，再 reduce。
- 个人日：个人月 + 目标日号，再 reduce。

个人日决定本次主要主题，其他数字作背景。缺生日只让该项不可用。生日不能晚于问卜当地日或目标日。生日及可反推出出生月日的中间加数不进入轨迹；生命数字等最终派生值会保留，这不等于匿名化承诺。

## 现代卢恩

24 Elder Futhark 符文，无空白符、无逆位，无放回抽三枚。名称采用现代常见学术重建写法，符号为 Unicode 对应字符，随包附 Noto Sans Runic 字体。三位置规则与塔罗共用结构，知识释义独立；不冒称统一的古代占卜法。

## 场景与汇总

本地规则不对自由文本作语义识别。v1.2 移除类别，行动模式使用 2–10 个不同 options 字符串；提交前去首尾空白、校验非空及每项≤300字，保留否定和顺序。不为选项打分、投票或重新抽取，同一冻结结果用于逐项反思。新记录剔除 category；旧 category/action 和没有 options 的记录仍可恢复且不重算。

下面的单行动白名单说明旧版规则，新表单不再输入单一 action 或普通日常范围勾选；多选项的新记录始终不强造本地倾向，模型建议另行标注。

行动倾向仅在用户确认普通日常范围，且场景和**完整行动字符串**匹配下列白名单时启用：

| 场景     | 行动             |
| -------- | ---------------- |
| 上课安排 | 去上课           |
| 任务推进 | 开始整理任务清单 |
| 休息安排 | 安排十分钟休息   |
| 沟通联系 | 整理想表达的内容 |

这份表曾在旧版输入旁明示，保留用于理解旧记录；不可用模糊关键词匹配替代。未适配时「无明确倾向」；开放探索始终只汇总主题。提示或变化主题映射到象征倾向，阻力位不能当作建议。遇到主题张力保留不同视角。

汇总只接收已经冻结的单引擎结果。列出共同主题、各自侧重及推进／等待休整间的张力。行动倾向只在选定范围内各完成结果倾向完全相同时复述，不做多数票；否则无明确倾向。相关体系提示与参与范围一直可见。任何偏好都不能改变原始结果。

## 本地存储与离线

历史仅在「保存本次」或「收藏本条」事件写入 localStorage，收藏会保存其所在完整记录以保留上下文。已主动保存的记录会同步后续偏好。未保存当前结果只进入 sessionStorage 用于本标签页刷新恢复。Zod 对恢复数据逐项校验；损坏历史不自动覆盖。关闭标签页后未保存记录可能被清理，也可能被浏览器的会话恢复保留。

生产构建包含全部知识、算法、字体，无动态知识请求；Service Worker 预缓存构建资源。资源完成初次缓存后支持离线刷新。首次打开仍需要下载静态资源。缓存按站点 scope 和内容摘要分组，不清理其他项目缓存；更新在旧标签页关闭后生效。忽略静态文件响应的 Vary（开发预览服务器会附带 Origin），避免 CORS 取资源模式差异导致离线错失缓存。

五套引擎的本地流程不上传文本、生日或遥测。可选的模型延伸遵循下一节；没有账户、支付、远程历法或数据库。GitHub Pages 和 Cloudflare 托管平台可能处理普通访问日志；本站不能控制平台自身日志。外部来源链接仅在用户主动点击时导航，站内算法不会访问它们。

## 独立的 AI 延伸（用户在 v1.1 授权新增）

`冻结单体系结果 → 前端白名单构造 → 用户主动点击 → Cloudflare Worker → DeepSeek → 单独的 enhancements 字段`

原始 Reading 与所有本地解释保持不变。服务器不参加抽取／历法／规则汇总，模型回复也不成为其他引擎的输入。每条回复保留实际模型名、提示版本、生成时间和发送上下文，跟随用户主动保存的记录。生成成功后不提供自动重写；要重新探索需明确建立新记录。

v1.2 起点击模型按钮默认发送问题、完整选项、所选一家结果、已有释义及模式／场景／目标日期，不发类别。v1.3 依用户要求移除按钮旁发送提示，发送范围仍在方法页与README公开；已移除的场景反思不再进入新请求。底层 includeContext=false 兼容旧调用，仍排除问题、行动、选项及反思；旧记录不变。不发送生日字段、问卜精确时刻、其他引擎与偏好。数字只带最终派生值，梅花只带卦象与体用，不带年月日時换算轨迹。

模型对主动点击发送的问题进行语义理解，文案独立标为 AI，可能出错。提示词版本 -4 要求「解析＋建议」两个短段，目标120–220字、一般≤300字，联系具体结果并优先给出一个日常选择方向和一个可行步骤，不反问、追问或要求补充信息。必要条件简短写出，其他备选最多一句；800 token上限、非思考模式。没有训练或微调权重，不人工截断完整回复；上游因长度终止的半答仍作为失败处理。仍保留否定词、不改抽取、不虚构经文、不提供高风险行动或政治推荐、不恐吓灾祸。提示词不是正确性保证。显示为纯文本，不执行返回的代码或 HTML。

## 动画与简化呈现

提交过场约2700ms，支持跳过／Escape／减少动态效果；模型等待动画随请求开始与结束，秒数只显示真实等待时长。结果装饰使用确定性 SVG／CSS，无随机数、网络或计算副作用，支持统一暂停。刷新与历史恢复不重复提交过场。依据、原文、过程和来源继续冻结在记录与导出中，结果卡不再展示技术详情；动效不改变上下爻、正逆位或原始数据。

v1.3 新记录另存 `SavedReading.tarotRevealed`（0／1／2的无重复子集），不属于冻结Reading。初始空数组，逐张点击只增加揭示位置；全开前隐藏塔罗主题／白话／AI并禁用汇总和导出按钮，其他体系照常呈现。部分进度写入会话，主动保存后同步历史。旧记录缺少此字段即视为全开，不重新抽取。结果页不再显示场景反思，既有冻结数据和导出仍保留。

模型前端请求使用基础AbortController、调用方取消监听和40秒计时器，覆盖取响应头与正文全过程，结束即清理监听与计时器；不使用2024年才普遍支持的AbortSignal静态组合／超时接口。参考 [MDN any()](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal/any_static) 与 [timeout()](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal/timeout_static)。网络错误不等于模型拒答，也不能仅凭浏览器错误判断域名在所有手机网络可达。

服务端固定 DeepSeek 官方地址、模型与输出上限，拒绝客户端自定义模型／密钥／上游URL。密钥存平台 Secret。请求具备字段／尺寸校验、Origin限制、超时、限流与无自动重试；上游错误不回传原始响应或凭据。Workers 原生限流是按节点近似控制，不是全球账单硬上限，详细边界见 worker/README.md。模型服务需联网，缓存只覆盖静态文件和本机保存的既有文字，不缓存远程 API 请求。
